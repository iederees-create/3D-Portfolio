# Butterflies Educare — School Website & Parent Platform

## LinkedIn project announcement

I recently worked on the digital experience for Butterflies Educare, a school bringing its public website, family communication and 2027 registration journey together.

The work goes beyond a homepage:
- Mobile-first school website with custom butterfly-inspired visual design
- Parent account and 2027 enrolment workflows with save-and-continue
- Private school dashboard for application reviews, communication and events
- Unified calendar and guest-class proposal process
- Supabase authentication, PostgreSQL and database Row-Level Security
- GitHub Pages deployment with automated build and release checks

A key design decision was keeping the school site welcoming while protecting learner information. The portfolio uses illustrations rather than screenshots of private accounts or children's records.

The public website is live; I am transparent about which end-to-end school workflows still need independent operational verification.
